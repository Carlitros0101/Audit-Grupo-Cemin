# Control de Auditorías

Página web estática para llevar la planificación de auditorías a partir del archivo Planificación Auditorias.xlsx.

Incluye resumen operativo, agenda mensual, asignaciones filtrables, carga por auditor, creación de asignaciones y exportación CSV.

## Publicación

El sitio está preparado para GitHub Pages mediante el workflow incluido. En el repositorio, entra a Settings > Pages y selecciona GitHub Actions como fuente si GitHub lo solicita.

La primera versión guarda las nuevas asignaciones en el navegador del dispositivo. Para que todos los usuarios vean y editen la misma información, la siguiente etapa debe agregar una base de datos y autenticación.
